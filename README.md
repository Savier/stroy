# Распроданность новостроек Ульяновской области

`developers.xlsx` — интерактивная книга без макросов, которую создаёт генератор.
Она открывается в Microsoft 365 или Excel 2021 и новее. Данные уже включены
в книгу, поэтому для просмотра интернет не нужен.

## Как пользоваться книгой

- На листе **Сводка** выберите отчётный месяц в **C1**.
- В поле **«Объединить начиная с года»** под таблицей выберите порог. Например,
  при выборе 2029 сводка покажет отдельные годы до 2029 и строку **2029+**.
  Если порог позже последней группы сайта, применяется последний доступный год.
- Лист **Расчёт ГГГГ+** показывает, какие годы вошли в объединённую строку,
  сколько м² продано и сколько м² в строительстве по каждой группе.
- На годовых листах приведены строки девелоперов, исходные проценты,
  проданные метры по группам и контрольные суммы площадей.

## Как считается распроданность

Сайт возвращает площадь строительства, распроданность и среднюю
стройготовность по каждому девелоперу за выбранный плановый год ввода.
Проданная площадь равна площади строительства, умноженной на распроданность.
Строка относится к одному из диапазонов по стройготовности девелопера.
Значения ровно 25% и 75% входят в средний диапазон.

Распроданность группы — сумма проданной площади, делённая на сумму площади
строительства в группе. Для строки ГГГГ+ сначала складываются площади
соответствующих годовых групп, затем вычисляется процент. Строки с отсутствующими
показателями исключаются из группового расчёта. Если знаменатель равен нулю,
в сводке отображается прочерк.

## Как обновить данные

Установите [uv](https://docs.astral.sh/uv/) и запустите из каталога проекта:

```sh
uv run report-strygotovnost
```

По умолчанию книга записывается в `developers.xlsx`. Другое имя можно
передать позиционным аргументом. Сохраняются три последних доступных отчётных месяца и все
плановые годы ввода, которые сайт возвращает за эти месяцы. Параметр
`--months` меняет число месяцев. Например:

```sh
uv run report-strygotovnost --months 12 developers-12.xlsx
```

[Клиент API](domrf.py) использует HTTPX с отключённым прокси и код региона
`73`. [Генератор](report_strygotovnost.py) записывает исходные данные и формулы
в Excel. [Источник данных — наш.дом.рф](https://xn--80az8a.xn--d1aqf.xn--p1ai/аналитика/распроданность-стройготовность?regionCd=73).

## Проверки кода

Ruff и ty входят в группу `dev`. uv устанавливает их из `uv.lock` при
запуске команд ниже. Для генерации книги параметр `--no-dev` исключает
эту группу.

```sh
uv run --locked ruff format --check
uv run --locked ruff check
uv run --locked ty check
```

Команда `report-strygotovnost` зарегистрирована в `[project.scripts]`
в `pyproject.toml`. Новые отчёты могут добавить там свои команды.
